## 子任务明细

### A. 数据模型 + 迁移
- `internal/module/course/`（`doc.go` 包注释）。
- `model.go` 6 struct（每导出字段行尾注释）+ TableName + 常量：
  - `CoursePlan`(course_plans)：Name/Description/CoverURL/TotalDays(90)/TotalWeeks(12)/ProductID(可空)/Status(0草稿1上架)/Sort/时间戳/DeletedAt。
  - `DailyLesson`(daily_lessons)：CourseID(idx)/DayIndex/Week/LessonType(1工作日2周六3周日)/VideoID(可空)/Title/Description/Sort/Status/DeletedAt；唯一(course_id,day_index)。
  - `LessonWord`(lesson_words)：LessonID(idx)/Word/Meaning/Phonetic/ContextSentence/IsRecur/RecurSeq/Sort。
  - `LessonPhrase`(lesson_phrases)：LessonID(idx)/Phrase/Meaning/Example/Sort。
  - `Enrollment`(enrollments)：UserID(idx)/CourseID(idx)/StartDate/Status(1进行2完成3过期)/CheckinCount/时间戳；唯一(user_id,course_id)。
  - `Checkin`(course_checkins)：EnrollmentID(idx)/DayIndex/CheckinDate/CreatedAt；唯一(enrollment_id,day_index)。
- errcode 17xxx：CourseNotFound17001/LessonNotFound17002/LessonLocked17003/NotEnrolled17004/AlreadyEnrolled17005/AlreadyCheckedIn17006。
- `internal/bootstrap/migrate.go` AutoMigrate 追加 6 表。
- 验证：build/vet/gofmt；重启建表；`SHOW TABLES`/`DESC`/`SHOW INDEX` 核对字段与唯一索引。

### B. 解锁引擎 + 报名/进度只读接口
- `unlock.go`：`unlockedDay = min(totalDays, ⌊now-startDate⌋+1)`；lesson 可访问判定（d<=unlockedDay 且 enrollment active）。
- `repository.go`：CoursePlan(ListOnline/GetByID)、Enrollment(GetByUserCourse)、DailyLesson(计数/今日课概要)。
- `service.go`：ListPlans、MyCourse(start_date/unlockedDay/checkin_count/今日课概要/今日是否已打卡)。
- `dto.go` PlanItem/MyCourseResponse；`handler.go`+`router.go` `GET /course/plans`、`GET /course/my`(Auth)；main.go 装配。
- 验证：SQL 直插 course+enrollment 验证只读与解锁计算。

### C. 今日课详情 + 打卡
- repo 补：DailyLesson(GetByCourseDay)、LessonWord/Phrase(ListByLesson)、Checkin(Exists/Create)、Enrollment(CheckinCount+1)。
- service 补：LessonDetail(校验报名+解锁→video+words+phrases+tasks+checked_in；未报名 ErrNotEnrolled/未解锁 ErrLessonLocked；locked 隐藏媒体)、Checkin(事务内校验+写+计数；重复 ErrAlreadyCheckedIn)。
- 跨模块复用 content（C 开工时定）：最小 VideoReader 接口 或 直接轻查 videos 表。
- `dto.go` LessonDetailResponse/CheckinRequest；`handler.go`+`router.go` `GET /course/lessons/:day`、`POST /course/checkin`。
- 验证：报名用户取 day1；未解锁→locked；打卡→count+1；重复→拒绝。

### D. 管理端 CRUD + 手动报名
- repo+service 补：CoursePlan CRUD、DailyLesson CRUD、词/句卡随 lesson 增删改、AdminEnroll(校验 user+course+未重复→建 enrollment,start_date 默认今天)。
- `dto.go` CourseInput/LessonInput(含 words/phrases 数组)/EnrollRequest。
- 路由：`/admin/courses` CRUD、`/admin/courses/:id/lessons`、`/admin/lessons/:id`、`/admin/courses/enroll`(Auth,角色留后续)。
- 验证：admin 建营+课+词句卡→上架→手动报名→再跑 B/C 的 App 流程。

### E. OpenAPI 契约 + 端到端验收
- `api/openapi.yaml` 补 course/course-admin 路径 + schemas（tag course/course-admin，沿用 Envelope/PageData/allOf）。
- Python 解析校验 paths/schemas + 无悬空 ref。
- 端到端验收：建营→报名→plans→my→今日课→打卡→重复拒绝→改 start_date 模拟第N天解锁→DB 核对。
- （可选）扩展 cmd/import 支持课表+词句卡 JSON 批量导入。
